# Ressources et licences

- `public/images/concept.png` : planche SLICER / BLOOM FLOW 02 fournie par le propriétaire dans cette conversation. Utilisée sur sa demande pour cette boutique. Ce dépôt ne prétend pas attribuer une licence publique à ce visuel.
- `front.webp`, `back.webp`, `detail.webp` : recadrages de cette même planche, compressés en WebP. Aucune photographie fabriquée ni fausse rotation 360°. La mention « visuel conceptuel » reste affichée.
- Rose et ruban : géométries procédurales originales dans `src/components/rose.tsx`, sans modèle 3D tiers. Six couches de pétales courbes et trois pétales détachés. Le repli visuel utilise le détail de la rose fourni.
- Trame : SVG déterministe, grille régulière et rayons variables, créé pour ce projet.
- Favicon et logo typographique : composition originale SLICER ; Barlow Condensed pour le logotype provisoire.
- Inter et Barlow Condensed : auto-hébergées via Fontsource, SIL Open Font License 1.1. Textes de licence inclus dans `licenses/`.
- Icônes : Radix Icons, MIT. Les autres licences de dépendances sont conservées dans leurs paquets npm, versions figées au lockfile.

Pour remplacer les concepts par des photographies réelles : téléverser les fichiers dans l’administration, saisir les descriptions accessibles, ordonner face/dos/détails et mettre à jour également la composition éditoriale de l’accueil. Confirmer les droits et ajuster les mentions « conceptuel » lorsque les fichiers réels sont disponibles.
